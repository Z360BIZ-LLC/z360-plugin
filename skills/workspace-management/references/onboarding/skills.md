# Skills

Task ID: `skills`

Read `../workspace-management/references/skill-management.md` and follow its workflow.

1. Review existing skills and confirmed organization context.
2. Identify the repeatable business procedures the agent should follow.
3. Create or refine only the skills the user approves.
4. If an onboarding preset was selected, follow [Onboarding presets](presets.md) for its skill resources before proposing changes.
5. Verify saved skill files and action references before marking the task done.
