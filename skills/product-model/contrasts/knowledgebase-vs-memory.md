# Knowledge base vs memory

The **knowledge base** contains durable, organization-authored documents, policies, facts, and procedures.

**Memory** contains retained context about people, organizations, preferences, or prior interactions.

## Boundary

Knowledge-base content is curated reference material in the product's folder and document model. Memory is contextual recall; it is not a substitute for publishing a document or organizing business knowledge.

Related definition, only if needed: [knowledge base](../references/knowledgebase.md). Memory is an agent-context concept rather than a workspace-management record.
