# Automations vs reminders

An **automation** starts recurring or event-driven agent behavior without a person initiating each run.

A **reminder** prompts a teammate to act later.

## Boundary

An automation is unattended agent behavior with a trigger contract. A reminder is a human follow-up record. A one-time return to the current agent thread is a wakeup, not either object.
