# Integrations vs action groups

An **integration** represents the external application or provider and the connection types it supports.

An **action group** represents one connection-specific capability and credential boundary for that provider, account, or tenant.

## Boundary

An integration can have multiple connected accounts and action groups. The integration is the provider-level concept; the action group is the scoped capability relationship used by a profile or run.
