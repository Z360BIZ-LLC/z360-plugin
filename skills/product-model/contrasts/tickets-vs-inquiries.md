# Tickets vs inquiries

A **ticket** represents an issue or request that needs resolution and ownership.

An **inquiry** represents a potential or existing customer's movement through a pipeline and lifecycle.

## Boundary

An inquiry can create work and a ticket can be linked to the same contact or conversation, but they answer different questions: “where is this customer in the lifecycle?” versus “what work must be resolved?”.
