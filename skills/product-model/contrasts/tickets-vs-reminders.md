# Tickets vs reminders

A **ticket** represents work that needs ownership, status, continuity, or follow-up beyond a single due time.

A **reminder** prompts a teammate to act later.

## Boundary

A reminder is a time-oriented prompt, not a durable work container. If the work needs a visible lifecycle or can be picked up after the reminder date, it is ticket-shaped.
