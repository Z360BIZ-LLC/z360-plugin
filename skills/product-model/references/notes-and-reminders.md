# Notes and reminders

A note preserves internal context about what happened, what was learned, or what a teammate should remember. It is a record of context, not an assignment or a customer-facing message.

A reminder tells a teammate that an action is due later. It is a time-oriented follow-up prompt, not a durable work container and not an instruction for the agent to resume a conversation.

Both notes and reminders can be attached to an existing conversation as composition messages. The conversation supplies the surrounding history; the note or reminder supplies the internal context or follow-up meaning. Neither one replaces a ticket when the work needs an owner and a lifecycle.
