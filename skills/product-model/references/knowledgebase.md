# Knowledge base

The knowledge base is durable, organization-authored context that the assistant can use when answering business-specific questions. It is organized as a tree of folders and documents and is separate from customer conversations and records.

A folder groups content and can contain nested folders or documents. A document contains the durable facts, policies, procedures, or other business material that belongs in that part of the tree. Website imports are still knowledge-base content once they are organized as folders and documents.

Knowledge-base items have a synchronization state because their content is made available to the assistant through a separate indexing or sync process. Content can exist in the tree before its latest version is synchronized.

The knowledge base is not memory. Knowledge-base content is organization-authored reference material; memory is retained context about people, organizations, or prior interactions. The knowledge base is also not the Library: Library files are shared attachments, while knowledge-base documents are curated business context.
