# Library

The AI Studio Library stores files and attachments shared with Ask Z. It can contain images, ordinary files, and generated or shared artifacts that users want to access through the AI Studio experience.

Library items are file assets, not customer records. They are not conversations, messages, knowledge-base documents, memory, skills, or Expert profiles. A file may support an interaction or be shared with an agent without becoming part of the organization's curated knowledge base.

The Library and the knowledge base serve different purposes: the Library preserves shared file assets, while the knowledge base organizes durable business information into folders and documents for assistant use.
